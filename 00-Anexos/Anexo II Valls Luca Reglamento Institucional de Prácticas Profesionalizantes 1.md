**Descripción del Proyecto de Práctica Profesionalizante**

| Título | stockify |
| :---- | :---- |
| **Objetivo** | Analizar y diseñar un sistema de gestión comercial que contemple los procesos de control de stock, ventas, facturación y administración de proveedores |
| **Docente tutor** | Sebastian R. Bruselario. |
| **Orientación específica** | Software. |
| **Vinculación e impacto** | El sistema permitirá mejorar la administración del almacén mediante la automatización del control de stock, ventas y proveedores. Su implementación reducirá aproximadamente un 50% el tiempo dedicado a tareas administrativas, agilizando procesos como la carga de productos, actualización de stock y registro de ventas. Además, disminuirá los errores en el manejo de mercadería, evitando diferencias entre el stock real y el registrado, faltantes de productos y compras innecesarias. |
| **Introducción** | El kiosco se dedica a la venta de productos comestibles, electrónicos y artículos de limpieza. Actualmente, el negocio presenta problemas en la gestión administrativa debido a la falta de un control de stock preciso y actualizado en tiempo real. Además, el registro de ventas y la gestión de proveedores se realizan de manera desorganizada, dificultando el seguimiento de la información, la reposición de mercadería y la correcta administración del comercio. |
| **Recursos** | El proyecto se apoyará en herramientas de modelado UML para la elaboración de diagramas de casos de uso, diagramas de secuencia y diagramas de clases, complementados con el modelo Entidad-Relación para el diseño de la base de datos y documentación narrativa para la especificación de los casos de uso. Como herramientas concretas se utilizarán: GitHub para el versionado y resguardo de la documentación , Draw.io para la confección de los diagramas y MySQL Workbench para el modelado de la base de datos. |
| **Metodología** | Metodologías ágiles |
| **Tareas a desarrollar** | Entrevistas, análisis de requerimientos funcionales y no funcionales con enfoque en estructura y técnica, confección del diccionario de datos, definición de reglas de negocio y elaboración de casos de uso. Además, incluye el modelado de datos y estructura mediante el diseño del modelo Entidad-Relación y el modelo de dominio, el diseño UML con diagramas de clases y de secuencia, y la aplicación de patrones de diseño.   |
| **Horas de trabajo semanales** | 5 hs semanales (3 hs de clase) |
| **Estimación de tiempos y plazos de realización** | Inicio 26/03/2026 – Finalización 13/11/2026. |
